# Book Inventory Management System (React)

## Description
A React-based web application to manage books with full CRUD operations.
It uses JSON Server as a mock REST API.

## Features
- Add, view, edit, delete books
- REST API integration using JSON Server
- Form validation (email, number, required fields)
- Table view with scrolling
- Responsive UI using Bootstrap

## Tech Stack
- React
- React Router
- Axios
- Bootstrap
- JSON Server

## How to Run
1. npm install
2. npm start
3. json-server --watch db.json --port 3001
